# 00. 부트스트랩 — CLAUDE.md 작성과 공통 규칙 확정

이 저장소(`myhandball-api`, NestJS)에 `CLAUDE.md`를 만들어 주세요. 이어지는 API
작업들이 일관되게 진행되도록 하는 기준 문서입니다. **코드는 아직 건드리지 않습니다.**

## 배경

이 API를 쓰는 클라이언트가 둘입니다.

1. **기존 React 웹** (`../_legercy/myhandball/apps/web`) — 운영 중, 건드리면 안 됨
2. **새 Flutter 앱** (`../myhandball-app`) — 시안의 전 화면이 이미 구현돼 있고
   데이터만 목업. API가 준비되는 대로 붙인다

앱은 화면이 다 만들어져 있어서 **응답 모양이 확정되면 구현체 하나만 추가하면
되는** 상태입니다. 그래서 이 API 작업의 성패는 "응답 스펙을 앱 도메인 모델과
맞추는 것"에 달려 있습니다.

## 먼저 파악할 것

작업 전에 아래를 읽고 현재 구조를 파악해 주세요.

- `src/app.module.ts` — 모듈 구성
- `src/schedule/`, `src/ranking/`, `src/team/` — 기존 스크래핑 서비스 3종.
  cheerio 파싱 방식, `absUrl`·`textOrNull` 같은 헬퍼, 캐시 사용 패턴
- `src/cache/` — Redis 래퍼
- `src/welcome/` — 유일하게 DB(TypeORM)를 쓰는 모듈. 05번 작업의 참고가 됨
- `.env.example`

## CLAUDE.md에 담을 내용

### 프로젝트 개요

- 한국 핸드볼 리그(H리그) 일정·순위·기록 API
- 데이터는 전부 `koreahandball.com` 스크래핑 (`.env`의 `BASE`)
- 전역 prefix `/api`, 인증 없음
- Redis 캐시, Postgres(TypeORM)는 `welcome` 모듈에서만 사용 중

### 클라이언트와 하위 호환

- 기존 웹이 `/api/schedule`, `/api/ranking`, `/api/team`을 쓴다
- **필드 추가는 되지만 제거·타입 변경은 금지**
- 새 엔드포인트는 자유롭게 추가 가능
- 웹을 내리기 전까지 이 제약이 유지된다

### 스크래핑 규칙

기존 서비스에서 이미 쓰고 있는 공통 파라미터를 표로 정리해 주세요:

| 파라미터 | 값 | 의미 |
|---|---|---|
| `league_gender` | `M` / `W` | 남자부 / 여자부 |
| `league_season` | `2025` | **시작 연도**. 2025 = 25-26 시즌 |
| `league_type` | `1` / `2` | 정규리그 / 포스트시즌 |
| `league_season_month` | `11` | 월 (일정에서만) |

그리고 원칙:

- **파싱 실패는 500이 아니라 빈 값 + 로그.** 원본 사이트 개편에 취약하므로,
  한 항목이 깨져도 나머지가 나가야 한다. 클라이언트는 빈 상태 화면을 갖고 있다
- 원본 HTML의 구조 변화를 빨리 알아채도록, 파싱 결과가 0건이면 `warn` 로그
- 절대 URL 변환은 기존 `absUrl` 패턴을 따른다

### 응답 스펙 원칙

- 타입은 각 모듈의 `types.ts`에 둔다 (기존 관례)
- 숫자로 쓸 값은 숫자로 준다. **기존 `GameItem.scoreText`처럼 `"20 : 23"` 문자열로
  주는 실수를 반복하지 않는다** — 새 필드는 `scoreHome: number | null` 형태로
- 날짜는 ISO 8601 문자열. 원본 라벨이 필요하면 `~Label` 필드를 따로 둔다
- 비어 있음은 `null` 또는 `[]`. `undefined`를 내보내지 않는다

그리고 각 문서가 어떤 엔드포인트를 만드는지 표로 적어 주세요.

### 검증 방법

```bash
pnpm --filter @koha/api dev     # 또는 이 저장소 루트에서 pnpm dev
curl -s 'http://localhost:3000/api/schedule?gender=M&season=2025&type=1' | jq
```

### 서버 운영 상태 (주의)

`myhandball.kro.kr`는 가정 회선 자체 호스팅입니다. 2026-09-23 기준 외부에서
443이 응답하지 않는 상태로 관측됐고, 인증서는 수동 갱신(ZeroSSL) 중입니다.

**앱은 웹과 달리 인증서가 만료되면 통째로 먹통이 됩니다** (iOS ATS / Android
cleartext 차단). 배포 관련 작업을 하게 되면 이 점을 먼저 짚어 주세요.

## 하지 말 것

- 아직 엔드포인트를 만들지 않습니다. 이 단계는 문서만입니다

  맥락**만 적습니다
