# 02. 선수 도메인 — `GET /api/player` 3종

선수 명단·상세·기록 랭킹 엔드포인트를 만듭니다.

## 배경

Flutter 앱에서 선수 데이터를 쓰는 곳이 많습니다:

- **분석 > 선수 탭** — 선수 카드 그리드 (배번·포지션·소속·시즌 기록)
- **선수 상세 시트** — 프로필 + 시즌 요약
- **선수 비교** — 두 선수의 기록을 레이더 차트로
- **홈 > 시즌 TOP5** — 카테고리별(득점·어시스트·선방) 상위 5명
- **MY > 관심 선수** — 하트로 저장한 선수
- **팀 상세 > 선수 탭** — 팀 소속 선수

**지금은 목업이 선수 이름까지 지어내고 있습니다** (김민준, 이서연 같은 식).
실제 데이터로 바꾸는 게 이 작업입니다.

## 데이터 출처

### `/record/player.php` — 선수 시즌 기록 전체

가장 중요한 페이지입니다. 표 헤더가 2단입니다:

```
1단: 선수 | 슛 | 공격 | 수비 | 리바운드 | 처벌 | 출전시간
2단: NO | 팀 | 이름 | 득점/슛 | % | 필드 득점/슛 | % | 6m | 윙 | 9m | 7m | ...
```

실측한 행 예시:

```
['1', '인천', '이요셉', '166/263', '63.12%', '113/201', '56.22%',
 '21/34', '0/0', '45/107', '53/62', '32/41', '13/17', '2/2']
```

- 첫 칸은 **순위**, 팀명은 축약형(`인천`, `충남`)입니다
- `"166/263"`은 **성공/시도**입니다. 숫자로 쪼개서 주세요

쿼리 파라미터는 다른 페이지와 같습니다 (`league_gender`, `league_season`,
`league_type`). **직접 받아서 확인하세요** — 이 페이지만 다른 이름을 쓸 수 있습니다.

### `/introduce/player_detail.php?player_seq=101` — 선수 프로필

실측 내용:

```
No.32 [하남시청]
김지훈  JIHOON KIM / LW
출생        1997년 2월 3일
신장/체중    176cm/78kg
출신학교     경희대학교

정규리그 통산기록
경기수 | 득점 | 필드 득점 | 어시스트 | 공격포인트 | 윙 득점 | 9M 득점 | 7M 득점 | 블록샷 | 경기시간
155   | 371 | 330      | 65      | 436      | 63     | 7      | 41     | 4     | 7189:51

(이어서 시즌별 기록 표. '2025-2026' 같은 시즌 라벨과 함께)
```

`player_seq`는 `/game/playerranking.php`와 팀 페이지의 링크에서 얻습니다:
`/introduce/player_detail.php?player_seq=1153`

### `/game/playerranking.php` — 카테고리별 랭킹

`div.ranking_wrap`에 `득점 TOP5` 형태로 들어 있습니다:

```
1위  이요셉  CB / No.30  인천도시공사  166 골
2위  육태경  CB          충남         164 골
```

카테고리가 여럿인지(득점 외 어시스트·선방 등) **페이지를 받아서 확인하세요.**
`select[name=league_type]`, `select[name=league_season]` 필터가 있습니다.

### `/introduce/player_search.php` — 선수 검색

명단 전체를 얻는 더 나은 경로일 수 있습니다. **확인해 보고**, 더 적합하면
`/record/player.php` 대신 쓰거나 병행하세요.

### `/record/compare.php` — 선수 비교 (참고)

연맹이 제공하는 비교 화면입니다. 어떤 지표로 비교하는지 참고하면
앱의 레이더 차트 축을 실제 지표로 맞출 수 있습니다.

## 만들 엔드포인트

```
GET /api/player?gender=M&season=2025&type=1
GET /api/player/:playerSeq
GET /api/player/ranking?gender=M&season=2025&type=1&category=goals
```

`src/player/` 모듈을 새로 만듭니다.

## 응답 스펙

```ts
// src/player/types.ts

export type PlayerPosition =
  | "LW" | "RW" | "LB" | "RB" | "CB" | "PV" | "GK" | string;

/** 목록·랭킹 공통으로 쓰는 시즌 기록 */
export interface PlayerSeasonStats {
  games: number;
  goals: number;
  shots: number;
  goalRate: number | null;        // 63.12 (퍼센트, 숫자)
  fieldGoals: number;
  fieldShots: number;
  goals6m: number;
  attempts6m: number;
  goalsWing: number;
  attemptsWing: number;
  goals9m: number;
  attempts9m: number;
  goals7m: number;
  attempts7m: number;
  assists: number;
  blocks: number;
  steals: number;
  turnovers: number;
  playTime: string | null;        // "7189:51"
}

export interface PlayerItem {
  playerSeq: number | null;       // player_detail.php?player_seq=
  name: string;
  number: number | null;
  position: PlayerPosition | null;
  teamName: string;               // 전체 이름으로 정규화 ("인천" → "인천도시공사")
  teamNum: number | null;
  teamLogoUrl: string | null;
  rank: number | null;            // 해당 카테고리 순위 (목록에서는 득점 순위)
  stats: PlayerSeasonStats;
}

export interface PlayerListResponse {
  url: string;
  gender: "M" | "W";
  season: string;
  type: string;
  players: PlayerItem[];
}

export interface PlayerDetailResponse {
  url: string;
  playerSeq: number;
  name: string;
  nameEn: string | null;          // "JIHOON KIM"
  number: number | null;
  position: PlayerPosition | null;
  teamName: string;
  teamNum: number | null;
  teamLogoUrl: string | null;
  photoUrl: string | null;

  birthDate: string | null;       // ISO "1997-02-03"
  birthLabel: string | null;      // "1997년 2월 3일"
  heightCm: number | null;
  weightKg: number | null;
  school: string | null;

  careerStats: PlayerSeasonStats;               // 정규리그 통산
  seasonStats: {                                // 시즌별
    season: string;                             // "2025-2026"
    stats: PlayerSeasonStats;
  }[];
}

export type StatCategory =
  | "goals" | "assists" | "saves" | "steals" | "blocks";

export interface PlayerRankingResponse {
  url: string;
  gender: "M" | "W";
  season: string;
  type: string;
  category: StatCategory;
  unit: string;                   // "골" | "개"
  items: PlayerItem[];
}
```

### 팀명 정규화 — 중요

`/record/player.php`는 `인천`, `충남` 같은 **축약형**을 씁니다. 앱은 `인천도시공사`
같은 전체 이름으로 팀을 식별합니다.

기존 `TeamService`가 `/introduce/team_men.php`에서 전체 이름과 `team_num`을
가져오고 있으니, **그걸 참조해 축약형을 전체 이름으로 매핑**해 주세요.
매핑에 실패하면 원본 문자열을 그대로 두고 `teamNum: null`로 둡니다
(앱은 로고 없이 플레이스홀더를 그립니다).

남녀 양쪽에 같은 축약형이 있을 수 있으니(`인천도시공사` / `인천광역시청`)
`gender`를 함께 고려하세요.

## 캐시

- 목록·랭킹: TTL 1시간 (경기 후 갱신됨)
- 상세: TTL 24시간

## 검증

```bash
# 목록
curl -s 'http://localhost:3000/api/player?gender=M&season=2025&type=1' \
  | jq '{count: (.players|length), first: .players[0]}'

# 상세
curl -s 'http://localhost:3000/api/player/101' \
  | jq '{name, nameEn, number, position, teamName, heightCm, school,
         career: .careerStats.goals, seasons: (.seasonStats|length)}'

# 랭킹
curl -s 'http://localhost:3000/api/player/ranking?gender=M&season=2025&type=1&category=goals' \
  | jq '.items[:3] | map({rank, name, teamName, goals: .stats.goals})'
```

기대값:

- 목록 `first.name`이 `"이요셉"`, `stats.goals`가 `166`, `teamName`이
  축약형 `"인천"`이 아니라 `"인천도시공사"`
- 상세 `player_seq=101`이 `"김지훈"`, `nameEn` `"JIHOON KIM"`,
  `position` `"LW"`, `heightCm` `176`, `school` `"경희대학교"`,
  `careerStats.games` `155`
- 랭킹 1위가 득점 166

## 파싱이 깨질 때

- 표 구조를 못 읽으면 `players: []` + `warn` 로그
- 프로필의 개별 항목(출신학교 등)을 못 읽으면 그 필드만 `null`
- `player_seq`가 없는 선수는 `playerSeq: null`로 두되 목록에는 포함
